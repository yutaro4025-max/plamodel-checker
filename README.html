1. システム概要

毎朝の出勤登録から退勤通知・週次レポート生成まで、タスクスケジューラを使って自動化します。

各スクリプトの役割

スクリプト起動タイミング役割
Script-A_Register.ps1 毎朝（タスクスケジューラ定時起動） 出勤時間・予定退勤時間を入力。Script-B と WeeklyReport（金曜のみ）をその日分で動的登録する
Script-B_Notify.ps1 予定退勤の 5分前（Script-A が当日登録） 退勤準備リマインダーを表示。退勤ボタン押下で実退勤時刻を CSV に記録し、自タスクを削除する
WeeklyReport.ps1 金曜・予定退勤の 60分前（Script-A が当日登録） 当週の CSV ログと Outlook カレンダーを読み込み、HTML 形式の週次振り返りレポートを生成する

2. 前提条件

  • ✅ Windows 10 / 11
  • ✅ Windows PowerShell 5.1（OS 標準搭載）
  • ✅ Microsoft Outlook がインストール済みで起動可能な状態
  • ✅ OneDrive が同期済み（:OneDrive が設定されていること）
  • ✅ ログオン中のユーザーでタスクスケジューラが実行できること
⚠️
WeeklyReport は Outlook が起動している状態でないと正しくカレンダーデータを取得できません。金曜日の退勤前に Outlook を開いておいてください。

3. ファイル構成

  • Setup.bat UTF-8 BOMなし 初回セットアップ用。ダブルクリックで実行
  • Setup.ps1 UTF-8 BOM付き セットアップのロジック本体（Setup.bat から自動呼び出し）
  • Script-A_Register.ps1 UTF-8 BOM付き 出勤登録・タスク動的登録
  • Script-B_Notify.ps1 UTF-8 BOM付き 退勤通知・実退勤時刻記録
  • WeeklyReport.ps1 UTF-8 BOM付き 週次 HTML レポート生成
  • logs\script_a.log 自動生成 Script-A の実行ログ
  • logs\script_b.log 自動生成 Script-B の実行ログ
⚠️
全ファイルを同じフォルダに配置してください。フォルダパスに日本語が含まれていても動作します。

4. セットアップ手順（初回のみ）

  1. 全ファイルを同じフォルダに配置する
    5つの .ps1 ファイルと Setup.bat・Setup.ps1 をすべて同じフォルダに入れます。
  2. WeeklyReport.ps1 の CONFIG を確認する
    Outlook のカレンダーカテゴリ名が環境に合っているか確認してください（詳細は「CONFIG 変更箇所」参照）。
  3. Setup.bat をダブルクリックして実行する
    ダイアログが開くので、毎朝 Script-A を起動したい時刻を HH:MM 形式（例: 08:30）で入力します。
  4. タスクスケジューラで登録を確認する
    Win + R → taskschd.msc →「タスク スケジューラ ライブラリ」に AttendanceRegister があれば完了です。
ℹ️
起動時刻を変更したい場合は Setup.bat を再実行するだけで上書き登録されます。

5. 日常の使い方

月曜〜木曜

  1. 設定した時刻になると出勤登録ダイアログが自動表示される
  2. 出勤時間と予定退勤時間を入力して OK
  3. 予定退勤の 5分前に退勤通知が自動表示される
  4. 退勤したら「退勤しました」ボタンを押す（CSV に実退勤時刻が記録される）

金曜日

  1. 月〜木と同様に出勤登録を行う
  2. 予定退勤の 60分前に WeeklyReport が自動起動し、HTML レポートを生成する
  3. 予定退勤の 5分前に退勤通知が表示される
⚠️
WeeklyReport 実行時に Outlook が起動している必要があります。

CSV ログの保存場所

OneDrive\AttendanceLogsttendance_log.csv

OneDrive フォルダ配下に自動作成されます。「OneDrive - 会社名」形式のフォルダ名にも対応しています。

週次レポートの保存場所

OneDrive\AttendanceLogs\WeeklyReports\WeeklyReport_YYYY_WeekNN.html

ブラウザで開いて確認できます。

6. CONFIG 変更箇所

各スクリプト上部の CONFIG セクションで動作をカスタマイズできます。

Script-A / Script-B / WeeklyReport 共通

# OneDrive のログ保存先（通常は変更不要）
$ONEDRIVE_LOG_DIR = "$env:OneDrive\AttendanceLogs"
✅
:OneDrive を使っているため「OneDrive - 会社名」など環境差異は自動吸収されます。通常は変更不要です。

WeeklyReport.ps1

# Outlook カレンダーのカテゴリ名（ご自身の環境に合わせて変更）
$CAT_MEETING    = "会議"
$CAT_PACKAGING = "梱包"
$CAT_INTERNAL  = "社内業務"
$CAT_OTHER     = "その他"

# 昼休憩時間（分）
$BREAK_MIN = 60
⚠️
Outlook で実際に使っているカテゴリ名と完全一致させてください。一致しないカテゴリのイベントは「その他」に分類されます。

7. よくある質問

Q. 朝のダイアログが出なかった
タスクスケジューラで AttendanceRegister を右クリック →「実行」で手動起動できます。また「ユーザーがログオンしているときのみ実行する」設定になっているか確認してください。
Q. 退勤通知が来なかった
予定退勤時刻の 5分前がすでに過ぎていた場合は登録されません。また Script-A 実行時にダイアログをキャンセルした場合も登録されません。
Q. WeeklyReport でエラーになった
Outlook が起動していない場合に発生します。金曜日は Outlook を起動した状態で作業してください。
Q. 起動時刻を変更したい
Setup.bat を再実行して新しい時刻を入力するだけで上書き登録されます。
Q. Script-B のタスクが残っている
退勤ボタンを押さずにダイアログを閉じた場合、自己削除が行われません。タスクスケジューラから手動で削除してください（AttendanceNotify_YYYYMMDD）。
