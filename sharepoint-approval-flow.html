PART A — Excel ルーティングテーブルの構築

A1
Excel — ファイル作成と配置
SharePoint上に Excelファイルを新規作成する
操作内容
①SharePointの対象サイトを開く
②業務ファイルとは別のライブラリ（例: 「管理ツール」「自動化設定」）を用意、または既存ライブラリの管理用フォルダに移動する
③「新規」→「Excelブック」をクリック
④ファイル名を 承認ルーティング に変更して保存
配置場所の注意: 承認対象のライブラリ（荷姿設定書があるライブラリ）に置くと、このExcelファイルの更新もフローのトリガーになってしまう。必ず別の場所に配置すること。
A2
Excel — テーブル作成
テーブル T_ルーティング を作成する
操作内容
①Sheet1 のセル A1 から右方向に以下のヘッダーを入力する
 
A1: 製作所　　B1: 領域　　C1: 部門　　D1: 工程　　E1: パスキー　　F1: 宛先メール　　G1: 宛先名
列列名種類説明
A製作所手入力フォルダ名と完全一致する製作所名（例: 鈴鹿製作所）
B領域手入力領域フォルダ名
C部門手入力部門フォルダ名
D工程手入力工程フォルダ名
Eパスキー数式自動生成A〜Dを「/」でつないだ検索キー。Power Automateがパス一致に使用。
F宛先メール手入力この工程の承認者メールアドレス
G宛先名手入力承認者の表示名（参照用）
操作内容
②セル A1 をクリックし、「挿入」→「テーブル」をクリック
③範囲は $A$1:$G$1 のまま（後で行が増えれば自動拡張される）。「先頭行をテーブルの見出しとして使用する」にチェックを入れてOK
④テーブルが作成されたら、テーブルを選択した状態で「テーブルデザイン」タブ →「テーブル名」を T_ルーティング に変更する
A3
Excel — 数式設定
パスキー列（E列）に数式を設定する

パスキーは製作所〜工程のフォルダ名を「/」でつないだ文字列。Power Automate が SharePoint の {Path} と部分一致で照合するキーになる。

操作内容
①データ1行目のE列（E2）をクリック
②以下の数式を入力して Enter
 
=[@製作所]&"/"&[@領域]&"/"&[@部門]&"/"&[@工程]
操作内容
③テーブル形式になっていれば、新しい行を追加すると自動的にE列にも数式がコピーされる（手動コピー不要）
例: A2=「鈴鹿製作所」B2=「領域1」C2=「部門2」D2=「工程3」の場合、E2は自動的に 鈴鹿製作所/領域1/部門2/工程3 になる。
SharePointの{Path}の実値は /鈴鹿製作所/領域1/部門2/工程3/ファイル名.xlsx になるため contains（部分一致）で一致する。
A4
Excel — 初期データ登録
対象工程と承認者を登録する

試験運用では担当する工程だけ登録すればよい。未登録の工程はフローがスキップする（フォールバック処理で自分宛に送信）。

列入力例注意点
A: 製作所実際のフォルダ名をそのまま入力大文字・小文字・スペースを含めてフォルダ名と完全一致させること
B: 領域実際のフォルダ名をそのまま入力同上
C: 部門実際のフォルダ名をそのまま入力同上
D: 工程実際のフォルダ名をそのまま入力同上
E: パスキー（数式で自動生成）入力不要
F: 宛先メールapprover@example.comMicrosoft 365のメールアドレス
G: 宛先名山田（参照用）フローには使わないが管理用に入れておく
フォルダ名の確認方法: SharePointでフォルダを開き、URLまたはフォルダ名を直接コピーして貼り付けると確実。

C
PART C — メール本文（HTML）
B-8 の本文欄にコード表示モードで貼り付ける

貼り付け前の確認

本文欄の右上にある 「</>」ボタンをクリックしてHTMLモードに切り替えてから貼り付けること。
通常のテキストモードでは <a> タグが文字列として表示されリンクが機能しない。

本文 HTML （コード表示モードに切り替えてから全文を貼り付け）
<p> 様</p> <p>お世話になっております。</p> <p>下記の案件について、ご確認・承認をお願いいたします。</p> <hr> <p> ■ 案件名　　　：@{triggerOutputs()?['body/{Name}']}<br> ■ 登録日時　　：@{triggerOutputs()?['body/{Modified}']}<br> ■ 承認締切目安：@{formatDateTime(addDays(utcNow(),if(lessOrEquals(dayOfWeek(convertTimeZone(utcNow(),'UTC','Tokyo Standard Time')),2),3,5)),'yyyy年M月d日')} までにご対応をお願いします </p> <hr> <p>荷姿設定書をご確認のうえ、所定のセルにお名前をご記入ください。</p> <p><a href="@{triggerOutputs()?['body/{Link to item}']}">▼ 荷姿設定書を開く</a></p> <p>ご不明な点がございましたら、@{first(split(triggerOutputs()?['body/Editor/DisplayName'],' '))} までご連絡ください。</p> <p>よろしくお願いいたします。</p> <br> <p>--<br> [ここにOutlook「名前」署名の内容を貼り付け]</p>

動的コンテンツ対応表

本文内の参照式取得される内容
triggerOutputs()?['body/{Name}']ファイル名（案件名）
triggerOutputs()?['body/{Modified}']最終更新日時
triggerOutputs()?['body/{Link to item}']ファイルへのURL（<a>タグのhrefに使用）
triggerOutputs()?['body/Editor/DisplayName']更新者のフルネーム
first(split(..., ' '))フルネームの先頭部分（苗字）
締切日のformatDateTime式3営業日後（日本時間・週末回避）を「yyyy年M月d日」形式で出力

締切日の式（単体で「式」タブに貼り付けるとき）

formatDateTime(
    addDays(
        utcNow(),
        if(
            lessOrEquals(
                dayOfWeek(convertTimeZone(utcNow(), 'UTC', 'Tokyo Standard Time')),
                2
            ),
            3,
            5
        )
    ),
    'yyyy年M月d日'
)
D
PART D — 動作確認
フロー保存後、以下の順番でテストを実施する

確認手順

  • 【Excelテスト】T_ルーティングにテスト用の1行を入力し、パスキー列が正しく生成されているか目視確認する
  • 【フロー保存】Power Automateでフローを保存する。エラーが出る場合はアクション名の参照（特に「配列のフィルター処理」の表示名）を確認する
  • 【正常系①】登録済み工程フォルダにファイルをアップロードする → Outlook下書きフォルダに「【承認依頼】〇〇」が生成される
  • 【正常系②】下書きの宛先がExcelテーブルの「宛先メール」列の値になっているか確認する
  • 【正常系③】「▼ 荷姿設定書を開く」リンクをクリックしてファイルが開くか確認する
  • 【正常系④】締切日が週末になっていないか確認する（水〜土に実行して確認）
  • 【除外系①】未登録工程フォルダにファイルをアップロードする → 下書きが生成されない（スキップされる）
  • 【除外系②】他の人がファイルを更新する → 下書きが生成されない（ユーザー条件でスキップ）
  • 【Excelのみ変更テスト】Excelの宛先メールを変更し、同フォルダに再アップロードする → 新しい宛先で下書きが生成される（フロー無変更で反映されることを確認）

よくあるエラーと対処

エラー内容原因と対処
「配列のフィルター処理」でエラーアクションの内部名（表示名）が「配列のフィルター処理_1」など番号付きになっている場合、body('配列のフィルター処理') を body('配列のフィルター処理_1') に修正する
Excelテーブルが見つからないExcelファイルを開いてテーブル名が T_ルーティング になっているか確認。テーブル形式になっていない（単なる範囲になっている）可能性もある
宛先が空白でエラーcoalesce() のフォールバックアドレスが空になっていないか確認。自分のメールアドレスを入れておくこと
パスが一致しないComposeアクションでPath実値を確認し、Excelのパスキーと比較する。フォルダ名の大文字・小文字・スペースを一致させる
